1. PERSYARATAN SERVER (SYSTEM REQUIREMENTS)
================================================================================
Sebelum memulai, pastikan server Pterodactyl Anda memenuhi spesifikasi berikut:
- Tipe Egg         : Node.js (Yolks Node.js 20 atau Node.js 24)
- RAM Minimal      : 512 MB (Sangat disarankan: 1 GB - 2 GB)
- CPU Minimal      : 1 Core (50% - 100% CPU)
- Disk / Storage   : Minimal 1 GB (Untuk menampung node_modules & sesi WA)
- Port Allocation  : Minimal 1 Port (Port bebas yang diberikan oleh panel)

================================================================================
2. PERSIAPAN FILE PROJECT
================================================================================
Pastikan file project Anda sudah dikemas dalam format `.zip`.
Isi file zip tersebut harus mencakup:
- index.js              -> File utama script server
- package.json          -> Daftar modul & dependensi
- database.json         -> Database akun pengguna
- keyList.json          -> Penyimpanan sesi login
- permenmd/             -> Folder penyimpanan sesi WhatsApp (boleh kosong)
- assets/               -> Aset static gambar/media
- lib/                  -> Library pendukung

*Catatan: Jangan sertakan folder `node_modules` di dalam file zip Anda agar ukuran
file tetap kecil dan proses upload berlangsung cepat.*

================================================================================
3. CARA UPLOAD PROJECT KE PANEL PTERODACTYL
================================================================================
Terdapat dua cara mudah untuk memasukkan file project ke Pterodactyl:

A. CARA 1: LEWAT FILE MANAGER PANEL (Paling Mudah)
   1. Buka browser dan login ke Panel Pterodactyl Anda.
   2. Pilih server yang ingin Anda gunakan.
   3. Masuk ke menu "File Manager" (icon folder di sidebar kiri).
   4. Klik tombol "Upload" di kanan atas, lalu pilih file zip project Anda.
   5. Tunggu proses upload hingga 100%.
   6. Setelah file zip terupload, klik icon titik tiga (...) di sebelah file zip
      tersebut, lalu pilih "Unarchive" (Ekstrak).
   7. Semua file project akan otomatis keluar ke folder utama. File zip lama boleh
      Anda hapus untuk menghemat ruang disk.

B. CARA 2: LEWAT SFTP (FileZilla / WinSCP)
   1. Di panel Pterodactyl, masuk ke menu "Settings".
   2. Catat "SFTP Details" (IP Host, Port SFTP, dan Username).
   3. Buka software FileZilla di komputer/laptop Anda.
   4. Masukkan Host, Port, Username, dan Password panel Anda, lalu klik "Quickconnect".
   5. Seret (drag and drop) seluruh file project langsung ke direktori server.

================================================================================
4. KONFIGURASI STARTUP & VERSI NODE.JS
================================================================================
Agar server berjalan dengan benar tanpa error:
1. Masuk ke menu "Startup" di panel Pterodactyl Anda.
2. Periksa kolom-kolom berikut:
   - Startup Command:
     Pastikan berisi:
     `npm start` atau `node index.js`
   - Main File / Entrypoint:
     Pastikan diset ke: `index.js`
   - Node.js Version:
     Pilih versi `Node.js 20` atau `Node.js 24`.
     *(Jangan gunakan Node.js versi lama di bawah 18 karena Baileys membutuhkan
     dukungan Crypto & Fetch terbaru).*

================================================================================
5. INSTALASI DEPENDENSI (NPM INSTALL)
================================================================================
Sebelum server dinyalakan, modul pendukung harus diinstal terlebih dahulu:

1. Masuk ke menu "Console" di sidebar kiri.
2. Jika server Anda diatur otomatis menjalankan instalasi saat start, Anda cukup
   menekan tombol "START".
3. Jika ingin menginstal manual via Console:
   - Pastikan server dalam keadaan Stop.
   - Jalankan perintah:
     npm install
4. Tunggu hingga proses instalasi modul selesai dan muncul pesan:
   "added xx packages in xxs".

================================================================================
6. PENGATURAN PORT & DOMAIN (CLOUDFLARE TUNNEL)
================================================================================
Script `index.js` project ini sudah dilengkapi deteksi port otomatis:
`const PORT = process.env.PORT || process.env.SERVER_PORT || 3519;`

Artinya:
- Anda TIDAK PERLU mengubah kode port di dalam script!
- Script akan otomatis mendeteksi port alokasi berapapun yang diberikan oleh
  Pterodactyl pada server Anda (Contoh: port 25576, 3000, 8080, dll).

CARA MENGHUBUNGKAN KE DOMAIN SENDIRI (CLOUDFLARE TUNNEL):
Jika Anda ingin website Anda memiliki domain HTTPS rapi (misal: `https://api.domainanda.com`):
1. Buka dashboard Cloudflare Zero Trust (https://one.dash.cloudflare.com).
2. Masuk ke menu "Networks" -> "Tunnels" -> "Create a Tunnel".
3. Pilih "Cloudflared" dan beri nama tunnel Anda.
4. Salin token instalasi tunnel ke VPS host panel Anda.
5. Pada bagian "Public Hostname":
   - Subdomain : api (atau base-api)
   - Domain    : domainanda.com
   - Service   : HTTP
   - URL       : 127.0.0.1:<PortAlokasiPterodactylAnda>
6. Simpan konfigurasi. Sekarang server Pterodactyl Anda sudah aktif di internet
   dengan sertifikat SSL/HTTPS gratis dan aman dari DDoS!

================================================================================
7. MENJALANKAN SERVER (START / RESTART)
================================================================================
1. Masuk ke menu "Console" di panel Pterodactyl.
2. Klik tombol "START" (Warna Hijau).
3. Perhatikan log konsol. Jika berhasil, akan muncul pesan seperti berikut:
   --------------------------------------------------------------
   🚀 Server aktif di http://localhost:25576
   [AUTO REFRESH] Diatur setiap 30 menit sekali.
   [AUTOCLEAN LOGS] Diatur setiap jam 12 malam WIB.
   --------------------------------------------------------------
4. Buka IP server beserta port Anda di browser (atau gunakan domain tunnel Anda):
   Contoh: `https://base-api.ndichan.xyz`
   Anda akan melihat tampilan Landing Page Web resmi Base-API yang menandakan server
   sudah berjalan 100% sempurna!

8. STRUKTUR FILE PENTING YANG WAJIB DIJAGA
================================================================================
Saat Anda mengelola file di Pterodactyl, JANGAN PERNAH menghapus file/folder berikut
agar data pengguna dan nomor sender Anda tidak hilang:

1. `database.json`:
   Berisi seluruh data username, password, limit, dan role user Anda.
2. `keyList.json`:
   Berisi data login sesi aktif dan token aplikasi.
3. `permenmd/`:
   Folder ini berisi kredensial login akun WhatsApp yang telah ditautkan.
   Jika folder ini terhapus, Anda harus melakukan pairing ulang nomor WhatsApp Anda!
4. `tutorial.txt`:
   File dokumentasi yang bisa diakses langsung via web di `/tutorial.txt`.

================================================================================
9. CARA INTEGRASI DENGAN APLIKASI ANDROID (APK)
================================================================================
Setelah server Pterodactyl Anda aktif:
1. Buka project source code Android (Flutter) Anda.
2. Buka file: `lib/api_config.dart`.
3. Ganti URL `baseUrl` dengan URL domain server Anda:
   const String baseUrl = 'https://base-api.ndichan.xyz';
   *(Ganti sesuai domain/IP server Pterodactyl Anda).*
4. Compile/Build APK Anda menggunakan perintah:
   flutter build apk --release
5. APK siap dibagikan ke pengguna dan langsung terhubung ke server Pterodactyl Anda!

10. TANYA JAWAB & SOLUSI KENDALA (TROUBLESHOOTING)
================================================================================

Q1: Kenapa saat klik Start server langsung mati (Server marked as OFF)?
A1: Periksa tab Console untuk melihat pesan error. Kemungkinan penyebab:
    - Modul belum diinstal: jalankan `npm install`.
    - Versi Node.js di menu Startup salah: ubah ke Node.js 20 atau 24.
    - Ada file json yang rusak/korup: pastikan `database.json` formatnya valid.

Q2: Muncul error "EADDRINUSE: address already in use"?
A2: Port tersebut sedang dipakai proses lain. Matikan server terlebih dahulu
    (tombol STOP / KILL), tunggu 5 detik, lalu klik START kembali.

Q3: Bagaimana jika server restart, apakah nomor WhatsApp harus pairing ulang?
A3: TIDAK PERLU. Server ini sudah dilengkapi sistem auto-reconnect. Selama folder
    `permenmd/` tidak Anda hapus, server akan otomatis menghubungkan kembali seluruh
    nomor WhatsApp yang tersimpan saat server dinyalakan.

Q4: Kenapa muncul error "Invalid session key (401)" di aplikasi?
A4: Server project ini sudah memiliki fitur auto-recovery `getKeyInfo`. Pastikan
    aplikasi Anda versi terbaru agar otomatis merefresh key jika masa aktif habis.
