1. PENGENALAN & ARSITEKTUR SISTEM
================================================================================
Base-API adalah backend server berbasis Node.js yang berfungsi sebagai pusat kendali
untuk:
- Layanan autentikasi user (member, VIP, reseller, owner).
- Sistem Pairing WhatsApp tanpa scan QR (menggunakan 8-digit Pairing Code Baileys).
- Multi-session WhatsApp Sender Management (koneksi multi-device persisten).
- Engine pengiriman payload pesan bug/crash WhatsApp terstruktur.
- Remote management VPS / Server via SSH & WebSocket.

Spesifikasi Runtime:
- Bahasa: Node.js v20+ / v24+
- Library Utama: Express.js, @whiskeysockets/baileys, ws, pino, ssh2, axios
- URL Produksi: https://base-api.ndichan.xyz
- Port Default: 25576
- Container: Pterodactyl / Docker Container

3. CARA MENJALANKAN & DEPLOYMENT SERVER
================================================================================
A. Instalasi Dependensi:
   cd /var/lib/pterodactyl/volumes/9a7c295b-2f9c-498a-b95d-a9bbeda5bafb/
   npm install

B. Menjalankan Server secara Manual:
   node index.js
   
C. Menjalankan di Background (menggunakan PM2 jika tersedia):
   pm2 start index.js --name "base-api"

D. Mengelola via Docker Container:
   - Cek ID container:
     docker ps | grep 25576
   - Restart container:
     docker restart <container_id>
   - Melihat log realtime:
     docker logs -f --tail 50 <container_id>

4.1 AUTENTIKASI & MANAJEMEN PENGGUNA
--------------------------------------------------------------------------------

1. VALIDASI LOGIN (POST /validate)
   Digunakan oleh aplikasi Flutter saat user login dengan username & password.
   Endpoint: POST https://base-api.ndichan.xyz/validate
   Headers : Content-Type: application/json
   Body JSON:
   {
     "user": "ndika",
     "pass": "password_kamu",
     "androidId": "a1b2c3d4e5f6g7h8"
   }
   Respon Sukses (200 OK):
   {
     "valid": true,
     "key": "NDIKZ-SEC-KEY-XXXXX",
     "role": "vip",
     "expiredDate": "2027-12-31"
   }

2. CEK INFORMASI AKUN (GET /myInfo)
   Digunakan untuk validasi sessionKey atau auto-login saat aplikasi dibuka.
   Endpoint: GET https://base-api.ndichan.xyz/myInfo?key=<sessionKey>&username=<username>
   Respon Sukses:
   {
     "valid": true,
     "username": "ndika",
     "role": "vip",
     "expiredDate": "2027-12-31",
     "key": "NDIKZ-SEC-KEY-XXXXX"
   }

3. UBAH PASSWORD (POST /changepass)
   Endpoint: POST https://base-api.ndichan.xyz/changepass
   Body JSON:
   {
     "key": "NDIKZ-SEC-KEY-XXXXX",
     "oldpass": "pass_lama",
     "newpass": "pass_baru"
   }

4. MEMBUAT AKUN BARU (GET /createAccount atau GET /userAdd)
   Endpoint: GET https://base-api.ndichan.xyz/createAccount?key=<adminKey>&newUser=<username>&pass=<password>&day=<jumlahHari>

5. DAFTAR SEMUA PENGGUNA (GET /listUsers)
   Endpoint: GET https://base-api.ndichan.xyz/listUsers?key=<adminKey>

6. HAPUS PENGGUNA (GET /deleteUser)
   Endpoint: GET https://base-api.ndichan.xyz/deleteUser?key=<adminKey>&targetUser=<username>

4.2 PAIRING WHATSAPP & MANAJEMEN SESI SENDER
--------------------------------------------------------------------------------

1. REQUEST KODE PAIRING WHATSAPP (GET /getPairing)
   Menghubungkan nomor WhatsApp ke server menggunakan 8-digit Pairing Code.
   Mendukung semua format nomor internasional (tanpa spasi / tanda +).
   Endpoint:
   GET https://base-api.ndichan.xyz/getPairing?key=<sessionKey>&username=<username>&number=<nomorWhatsApp>
   
   Contoh Request:
   curl -s "https://base-api.ndichan.xyz/getPairing?username=ndika&number=6282241182487"

   Respon Sukses (200 OK):
   {
     "valid": true,
     "number": "6282241182487",
     "pairingCode": "NDIKA123"
   }

   Cara Memasukkan di WhatsApp:
   1. Buka WhatsApp di HP yang ingin ditautkan.
   2. Masuk ke Pengaturan / Titik Tiga -> Perangkat Tertaut (Linked Devices).
   3. Ketuk "Tautkan Perangkat" -> "Tautkan dengan nomor telepon saja".
   4. Masukkan kode 8-digit (misal: NDIKA123).
   5. Tunggu hingga status di server berubah menjadi ONLINE.

2. MELIHAT DAFTAR SENDER TERHUBUNG (GET /mySender)
   Mengambil semua nomor WhatsApp yang saat ini aktif dan online milik akun user.
   Endpoint:
   GET https://base-api.ndichan.xyz/mySender?key=<sessionKey>&username=<username>

   Contoh Request:
   curl -s "https://base-api.ndichan.xyz/mySender?username=ndika"

   Respon Sukses (200 OK):
   {
     "valid": true,
     "connections": [
       {
         "id": "6282241182487",
         "number": "6282241182487",
         "sessionName": "6282241182487",
         "name": "call me ndika",
         "status": "online",
         "source": "personal"
       }
     ]
   }

3. MENGHAPUS / MEMUTUS SESI SENDER (ALL /deleteSender)
   Memutuskan koneksi socket Baileys dan menghapus file sesi dari folder permenmd.
   Mendukung method GET, POST, maupun DELETE.
   Parameter yang diterima: key, username, id, sessionName, number.
   
   Contoh Request:
   curl -s "https://base-api.ndichan.xyz/deleteSender?username=ndika&id=6282241182487"

   Respon Sukses:
   {
     "valid": true,
     "message": "Sender deleted successfully"
   }

4. STATISTIK SENDER (GET /getSenderStats)
   Melihat jumlah sender aktif di server (private & global).
   Endpoint: GET https://base-api.ndichan.xyz/getSenderStats?key=<sessionKey>&username=<username>

4.4 MANAJEMEN SERVER / VPS (REMOTE CONTROL)
--------------------------------------------------------------------------------
Base-API dilengkapi fitur pengelolaan server VPS jarak jauh via protokol SSH:
- GET  /myServer    -> Menampilkan daftar VPS yang dimiliki user.
- POST /addServer   -> Menambahkan VPS baru (IP, Port, Username, Password).
- POST /delServer   -> Menghapus VPS yang tersimpan.
- POST /sendCommand -> Mengirimkan perintah Linux/Bash ke VPS dan membaca output.

5. INTEGRASI DENGAN APLIKASI ANDROID (BASE-APK FLUTTER)
================================================================================
Aplikasi Android (ndika-base-apk) berkomunikasi langsung dengan Base-API melalui
konfigurasi berikut:

1. Konfigurasi Endpoint:
   File: lib/api_config.dart
   const String baseUrl = 'https://base-api.ndichan.xyz';

2. Alur Penyimpanan Sesi di Aplikasi:
   - Setelah user berhasil login di `lib/login_page.dart`, data berikut disimpan
     secara lokal menggunakan SharedPreferences:
     * 'user' -> Username pengguna
     * 'pass' -> Password pengguna
     * 'key'  -> Session key aktif
     * 'role' -> Role akun (member / vip)

3. Penanganan Error 401 (Unauthorized):
   - Jika `sessionKey` di memori kadaluarsa, halaman Pairing (`lib/pairing_page.dart`)
     dan Bug Sender (`lib/bug_sender.dart`) secara otomatis:
     a. Menyertakan parameter `username` ke server.
     b. Membaca ulang key terbaru dari SharedPreferences.
     c. Menyediakan tombol "LOGIN ULANG KE APLIKASI" jika sesi benar-benar expired.

4. Penanganan ID Sesi Sender:
   - Data sender dari `/mySender` menyediakan properti lengkap: `id`, `number`,
     `name`, dan `sessionName`.
   - Tombol hapus sesi memanggil:
     /deleteSender?key=<key>&username=<user>&id=<id>&sessionName=<id>
     sehingga tidak akan terjadi error "id is required".

6. TIPS PERAWATAN, BACKUP & TROUBLESHOOTING
================================================================================

1. Error: "Invalid session key (401)"
   Penyebab : Kunci sesi user tidak ditemukan di memori server.
   Solusi   : Server kini telah dilengkapi helper `getKeyInfo(key, username)`
              yang otomatis mencocokkan username dengan file `keyList.json` dan
              `database.json` serta meregenerasi cache sesi tanpa harus login ulang.

2. Error: "Sender id is required (400)"
   Penyebab : Parameter `id` tidak disertakan saat memanggil `/deleteSender`.
   Solusi   : Pastikan URL menyertakan `&id=<sessionName>&sessionName=<sessionName>`.

3. Mengatasi Disk Penuh Akibat Pre-Keys Baileys:
   Folder sesi di `permenmd/<user>/<number>/` dapat mengakumulasi ribuan file
   pre-key. Lakukan pembersihan rutin berkala pada file `pre-key-*.json` lama
   dengan tetap mempertahankan `creds.json`.

4. Cara Melakukan Backup Database:
   Salin file-file penting berikut ke tempat aman secara berkala:
   - database.json (akun pengguna)
   - keyList.json (daftar session key)
   - vps.json (daftar server SSH)
   - folder permenmd/ (sesi WhatsApp yang aktif)
